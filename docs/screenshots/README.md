# Screenshots

Place capture artifacts here:

- `home-2d.png` — Home in 2D view (default mobile)
- `home-3d.png` — Home in 3D Globe view (default desktop)
- `layers-active.png` — Layer panel with EONET + ISS + Aircraft enabled
- `iss-pass.png` — ISS panel with pass predictor + .ics export

## How to generate

```bash
npm run dev
# open http://localhost:5173/EarthRadar/ in Chrome
# DevTools → Cmd+Shift+P → "Capture full size screenshot"
# rename and drop here
```

Recommended viewport sizes:
- Desktop: 1440 × 900
- Mobile: 390 × 844 (iPhone 14 Pro)
